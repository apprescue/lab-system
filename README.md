## Overview

This repository documents real-world debugging, security analysis, and infrastructure design across modern AI-driven applications.

The focus is on identifying, diagnosing, and resolving issues commonly found in rapidly built applications using AI tools, third-party platforms, and external APIs.

---

## Methodology

Each project follows:

1. Build minimal system  
2. Identify failure points  
3. Reproduce issues  
4. Debug root causes  
5. Apply fixes  
6. Improve security  
7. Migrate to AWS  
8. Document findings  

---

## Objective

To demonstrate practical approaches to debugging, securing, and scaling modern AI-driven applications in production environments.
